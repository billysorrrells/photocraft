Billo Photo portable mode

While this file sits next to photocraft.exe, Billo Photo keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the Billo PhotoData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move Billo Photo with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Photocraft) instead.
If Billo PhotoData can't be written (for example on a read-only drive), Billo Photo says so and
uses %APPDATA%\Photocraft instead.
